# Screenshot Capture Guide — Full-Stack Portfolio

This guide outlines recommended screenshots to capture and include in the repository (`docs/screenshots/`) for visual review by recruiters and engineering managers.

---

## Recommended Screenshots

1. **`landing-hero.png`**:
   - **View**: Public landing page hero section showing the interactive 3D particle canvas, title, and typography.
   - **Context**: Highlights frontend design capability and Three.js integration.

2. **`projects-section.png`**:
   - **View**: Featured Projects grid displaying cards with tech stack badges, live links, and repository buttons.
   - **Context**: Showcases structured data rendering and clean UI polish.

3. **`admin-dashboard.png`**:
   - **View**: Authenticated administrator dashboard displaying summary cards and management tables.
   - **Context**: Demonstrates full-stack CRUD capabilities and role-based access control.

4. **`admin-messages.png`**:
   - **View**: Admin contact message inbox showing inquiries and read/unread status toggles.
   - **Context**: Illustrates backend integration with secure communication channels.

---

## How to Add Screenshots
1. Capture screenshots of the running application (`http://localhost:5173` and `http://localhost:5173/admin`).
2. Save them as compressed PNG files inside `docs/screenshots/`.
3. Reference them in the root `README.md` using relative markdown image links:
   ```markdown
   ![Landing Hero](docs/screenshots/landing-hero.png)
   ```
